PAD SELECT — ゲームコントローラーアフィリエイトサイト 初期パッケージ

内容:
- index.html: トップページ
- style.css: レスポンシブデザイン
- articles/: 購入ガイドと用途別記事4本
- privacy.html: プライバシーポリシーのたたき台
- disclosure.html: 広告・免責事項のたたき台
- contact.html: お問い合わせ案内

公開前に必ず行うこと:
1. 商品リンクを、自分のASPアカウントで発行したアフィリエイトリンクへ差し替える。
2. 商品の型番、対応機種、価格、在庫、保証などを販売元・メーカー公式情報で確認する。
3. 運営者情報と問い合わせ先を実際の内容に更新する。
4. プライバシーポリシーを、実際に導入する解析・広告ツールに合わせて調整する。
5. 独自の経験・比較・検証を加えて、記事の質を高める。
6. Amazonアソシエイトを利用する場合は、最新の公式規約と表示要件を確認する。
7. ホスティングへアップロードし、スマホ表示・リンク・ページ遷移をテストする。

注意:
- サンプルの販売リンクは、あなた専用のアフィリエイトリンクではありません。
- このパッケージは静的サイトです。フォーム送信、商品価格の自動更新、クリック解析は実装していません。
- Amazonの公式商品画像やロゴは無断でコピーせず、各プログラムの規約に従ってください。
- 成果や収益は保証されません。
